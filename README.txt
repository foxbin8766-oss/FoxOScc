FOX OS Chromebook Companion v0.8

FOX OS itself remains a BONELAB code mod. This Chromebook companion is the local development/control environment.

New in v0.5:
- Device Bridge with a virtual Quest simulator (no physical Quest required)
- Memory Core with local project snapshots and JSON backup
- Permissions center for explicit capability controls
- Agent workspace with Evan and additional project agents
- General-purpose Game Studio prototype with play mode and scene objects
- World Builder with a lightweight scene canvas
- Expanded command palette
- Existing Projects, Code, FOX Circuits, Simulator, Systems, Browser, Build/Logs, Docs and Settings retained
- Offline-first local storage and PWA support

Important:
- The Quest simulator is virtual; it does not claim a physical Quest is connected.
- BONELAB DLL compilation/deployment remains a future integration point.
- Data is stored locally in the browser/PWA unless you export it.


New in v0.8:
- v0.7 UI retained as the base.
- Stronger local workspace persistence with migration from v0.7 data.
- Autosave indicator and explicit Save button.
- Full workspace import/restore, including custom pages and circuits.
- My Pages system with reusable live blocks, editable notes, tasks, memories, builds, project files, bookmarks, notifications, stats, links and launchers.
- Custom page icons, subtitles, tags, columns and sidebar pinning.
- Custom page block editing, reordering, duplication and deletion.
- Saved circuit node positions and run counts.
- Browser last URL persistence and better bookmark persistence.
- Custom Pages and Workspace Storage added to System Registry.
